# 商业化方案

> 目标：让免费用户「零摩擦地用起来」，让付费用户为**省时间和专业场景**付钱，
> 而不是为「能不能用」付钱。投屏本身永远免费 —— 这是获客成本最低的口碑策略。

## 2. 为什么这套定价能成立

1. **免费版就是完整产品**（1080p30 全功能）。用户不会因为「只能看 480p」而卸载并给 1 星。
2. 付费点是**时间成本**：60 分钟限制刚好卡在「开会/直播/教学」这个付费意愿最强的场景之后。
3. 买断价 128 = 2.6 年订阅，专门接住「讨厌订阅」的中国用户；
   这两个价格档同时存在，会让年付显得划算 —— 这是刻意的锚定。
4. 商用授权是**真正的利润来源**：门店广告屏、学校机房、展会展台，一台设备一年 ¥38 是零头。

## 3. License 技术方案（离线验签，不联网）

### 3.1 token 格式

```
LC1.<base64url(payload_json)>.<base64url(signature)>
```

`payload_json`（UTF-8，字段序无关）：

```json
{ "v": 1, "sub": "cus_PzX8…", "plan": "pro_lifetime", "seats": 3,
  "iat": 1735689600, "exp": 0, "mid": "9f3a1c4b", "org": null }
```

- `exp = 0` 表示买断永久有效。
- `mid` 是购买时绑定的设备指纹（Android `ANDROID_ID` 的 SHA-256 前 8 字节；桌面取主板+MAC 哈希）。
  换设备时客户端提示「还剩 N 次转移」，转移由服务端重签，`seats` 内免费。

### 3.2 验签

- 算法：**RSA-2048 + SHA-256**（`RSASSA-PKCS1-v1_5`）。
  故意不用 Ed25519：Android 8/9 上 `EdDSA` 支持不完整，而 `SHA256withRSA` 从 API 1 就有。
- 公钥内嵌在四个客户端里（`core/license/PublicKey.kt`、`web/js/license.js`…），私钥只在 `server/`。
- 校验顺序：`签名 → v → plan 白名单 → exp → mid 是否匹配（不匹配则进入 7 天宽限期）`。
- **失败不崩溃**：静默降级到 Free，并在设置页给出「重新激活」入口。

### 3.3 反滥用（务实，不求完美）

- 客户端**不联网**校验，所以「改系统时间绕过 exp」是可能的 —— 接受它。
  订阅靠**每年重签**自然续费，愿意破解的用户本来也不会付钱，但他们贡献口碑。
- 主机与观看端**双向**校验：主机发流时把 `free` 置位，观看端的 Pro 能力（回控/录制）按**本机** license 判定。
  这样「一台 Pro 手机 + 一台 Free 电脑」也能回控，符合用户直觉，也降低了白嫖动机（白嫖者拿不到 Pro 主机侧能力）。
- 服务端记录 `mid` 与 `sub`，同一 `sub` 30 天内超过 5 个不同 `mid` 自动进入人工审核队列。

## 4. 服务端接口（`server/`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/v1/checkout` | 创建 Stripe Checkout Session，`?plan=yearly\|lifetime\|team` |
| `POST` | `/v1/webhook/stripe` | 校验签名，`checkout.session.completed` → 签发 license → 邮件 |
| `POST` | `/v1/license/reissue` | 换机重签（需 `sub` + 旧的 mid，限 `seats` 次） |
| `GET` | `/v1/license/verify` | 可选在线校验（企业版用，可审计） |
| `GET` | `/v1/discount/edu` | 教育折扣码 |
| `GET` | `/healthz` | 探活 |

签发脚本（离线也能用）：

```bash
npm run sign -- --sub cus_test --plan pro_lifetime --seats 3 --mid 9f3a1c4b
# → LC1.eyJ2IjoxLC...  eyJhbGciOi...
```

## 5. 增长

- **零成本渠道**：GitHub + APK 直装（不依赖商店，规避「投屏类应用」审核摩擦）+ V2EX/小红书/B 站「手机变副屏」内容。
- **免费版水印**是唯一广告，文案固定为 `LumoCast · lumocast.app`，不打扰。
- **推荐奖励**：邀请 3 人解锁 1 个月 Pro（服务端发 30 天 license，`exp = now + 30d`）。
- 企业线索收集：设置页「需要发票/批量授权」表单 → 工单。

## 6. 诚实的产品承诺（写进商店页面与 README）

- 不收集屏幕内容、不收集设备标识以外的信息、无账号、无云。
- v1 **不是** E2EE；安全边界是「你信任当前 Wi-Fi」，PIN 用于防误连而非抗攻击。
- 需要 Android 8.0+ 才能当发送端；iOS/桌面只能接收（系统限制，非我们偷懒）。
