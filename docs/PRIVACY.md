# 隐私政策

**一句话：LumoCast 不收集任何数据。没有服务器，没有账号，没有统计。**

最后更新：2026-10-25

## 我们收集什么

什么也不收集。

App 不含任何分析 SDK、崩溃上报 SDK、广告 SDK 或热更新 SDK。你可以用抓包工具验证：除了你自己的设备，它不向任何域名发起连接。

## 数据在哪里流动

```
你的手机 ──── 你的 Wi-Fi 路由器 ──── 你的电脑/平板/另一台手机
                  （无互联网出口）
```

- 屏幕画面和声音**只**在你指定的那台设备和你之间点对点传输。
- 没有任何中继、云端转码、账号同步。
- 「发现设备」用的是局域网 UDP 广播，广播包不会离开你的子网。

## 权限用在哪

| 权限 | 用途 | 不授予会怎样 |
| --- | --- | --- |
| 屏幕捕获（MediaProjection） | 唯一用途：读取你要投屏的画面。每次开始共享都必须你手动确认 | 无法投屏 |
| `RECORD_AUDIO` | **不是录麦克风**。Android 强制要求此权限才能用 AudioPlaybackCapture 采集「本机正在播放的媒体声音」 | 投屏没有声音，画面正常 |
| `POST_NOTIFICATIONS` | 显示「正在共享」常驻通知，方便你随时停止 | 通知不显示，共享照常 |
| 本地网络（iOS） | 发现同一 Wi-Fi 的设备 | 搜不到设备，可用二维码连接 |

麦克风**从未被打开**。如果你不放心，可以在系统设置里把「麦克风」权限单独关掉，投屏与声音都不受影响。

## 没有账号，也没有支付

1.1.0 起 App 内不存在任何付费入口、订阅或授权码，因此也没有任何订单、支付信息需要保管。

## 儿童隐私

不适用：我们不收集任何人的任何数据。

## 变更

本政策如有变更，会以 commit 形式出现在本仓库，历史可查。
